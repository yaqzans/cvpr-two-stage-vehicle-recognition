PROJECT TITLE
================================================================================

Fine-Grained Vehicle Classification from Bangladesh Road Scenes Using a
Two-Stage Deep Learning Framework

Core pipeline:

Road scene / camera image
    -> Stage 1: YOLO object detector
    -> predicted bounding boxes
    -> crop each detected object
    -> Stage 2: fine-grained image classifier
    -> final Bangladesh road-object / vehicle class

Research motivation:

The project is not generic vehicle/non-vehicle recognition. It targets
Bangladesh-specific traffic classes in cluttered road scenes, with particular
interest in confusing or visually similar categories such as rickshaw versus
rickshaw_van and auto_rickshaw versus micro_bus. The intended use case is
autonomous driving / intelligent transportation in Bangladesh.

The detector must work on full, cluttered road scenes. The classifier receives
a much cleaner crop and independently makes the fine-grained class decision.

================================================================================
STAGE 1 MODEL DECISION
================================================================================

Chosen primary detector:
    YOLO26n (Nano)

Reason:
    The Stage 1 detector should be lightweight for road-scene / real-time use.
    YOLO26n is the current Ultralytics nano detector family selected for the
    primary experiment. It is approximately 2.4M parameters and 5.4 GFLOPs
    after fusion according to the referenced Ultralytics documentation.

Optional later comparison:
    YOLO26s — accuracy/speed comparison only.

Models intentionally not selected for the first experiment:
    YOLO26m, YOLO26l, YOLO26x

Reason:
    They conflict with the lightweight deployment motivation and are not needed
    for the first research baseline.

Training decision:
    Train YOLO26n as a normal 13-class detector on original RSUD20K scenes.
    Do not remove person. Do not use crop data for Stage 1.

Inference decision:
    YOLO’s normal class prediction is retained as a detector output and can be
    analyzed, but it will not be the final decision in the proposed two-stage
    pipeline. Accepted detected boxes are cropped and sent to Stage 2, which
    independently produces the final class decision.

================================================================================
PREPROCESSING DECISIONS FOR STAGE 1
================================================================================

The original RSUD20K data were already in YOLO-compatible layout. Therefore:

    - Do not crop original images for YOLO training.
    - Do not randomly re-split the dataset.
    - Do not overwrite/rescale the source images on disk.
    - Preserve the provided train / validation / test separation.

Required preprocessing:

    - Verify image/label pairing.
    - Verify class IDs are 0 through 12.
    - Verify every annotation has five numeric YOLO fields.
    - Verify normalized box dimensions and coordinates are valid.
    - Confirm images are readable.
    - Provide an exact YOLO data.yaml class mapping.

Handled by Ultralytics during training:

    - Letterbox resize to 640 x 640.
    - Tensor conversion and normalization.
    - Training-only augmentation.

Selected moderate augmentation:

    horizontal flip: 0.5
    vertical flip: 0.0
    rotation: 0.0 degrees
    translation: 0.10
    scale: 0.50
    HSV hue: 0.015
    HSV saturation: 0.70
    HSV value: 0.40
    mosaic: enabled, closed for the final 10 epochs

Avoided augmentation:

    vertical flips and aggressive rotation/warping, because upside-down road
    vehicles are not realistic Bangladesh road scenes.

Class imbalance note:

    Person, rickshaw, private_car, and motorcycle are frequent. Truck,
    pickup_truck, covered_van, and human_hauler are much rarer. First run uses
    normal training. Rare-class results must be reported with per-class AP.
